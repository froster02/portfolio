# portfolio

Personal portfolio website for Arush Naudiyal — Senior Backend Engineer.

## Tech Stack

- Vanilla HTML5, CSS3, JavaScript (no build tools required)
- Font Awesome 6 for icons
- GitHub Readme Stats for live GitHub metrics
- WakaTime for coding activity badge

## Usage

Open `index.html` in any modern browser. No server required.

```bash
open index.html
```

## Structure

- `index.html` — Main page content
- `styles.css` — All styles (dark/light theme, responsive)
- `script.js` — Interactions, animations, theme toggle
